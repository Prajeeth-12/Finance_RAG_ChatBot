\section{1. Executive Summary \& Problem Statement}
Dense corporate financial reports (such as quarterly earnings releases and 80+ page filings) present a major bottleneck for financial analysts. Locating specific quarterly metrics (e.g., Revenue, EBIT, or Net Income) requires tedious manual search and is prone to error.

\textbf{HCLTech Financial RAG Intelligence} is an enterprise-grade AI chatbot system designed to parse, index, and query HCLTech's FY26 quarterly reports (Q1--Q4). Built using \textbf{NVIDIA NIM Microservices} and \textbf{ChromaDB}, it delivers grounded, instant answers with exact source document citations while enforcing a \textbf{0\% Math Hallucination Guardrail}.

% --- KEY ENGINEERING INNOVATIONS ---
\section{3. Key Engineering Innovations \& Guardrails}

\begin{itemize}[leftmargin=1.5em]
    \item \textbf{0\% Math Hallucination Guardrail:} Enforces strict prompt rules that prevent the LLM from inventing figures, performing arbitrary arithmetic, or dividing annual totals to estimate quarterly metrics.
    \item \textbf{Hybrid Domain Re-Ranking:} Combines vector cosine similarity with financial domain-specific heuristic scoring (quarter scoping + metric keyword boosting + annual penalty weights). This prevents vector search from confusing annual figures with quarterly numbers.
    \item \textbf{NVIDIA NIM Batched Vector Indexing:} Utilizes high-throughput batched API requests (32 chunks per batch) to index 244 financial chunks into ChromaDB in under 5 seconds.
    \item \textbf{Interactive Process Pipeline UI:} Features a live single-line status bar tracking scope parsing, vector search latency, and LLM synthesis timing.
\end{itemize}

\vspace{0.8em}

% --- END-TO-END PIPELINE ---
\section{4. End-to-End System Pipeline}

\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{PDF Extraction \& Chunking:} Extracts text from \texttt{HCLTech\_Q1\_FY26.pdf} through \texttt{Q4\_FY26.pdf} and creates 244 structured text chunks tagged by source quarter.
    \item \textbf{Vector Store Generation:} Embeds chunks using \texttt{nvidia/nv-embedqa-e5-v5} (\texttt{input\_type="passage"}) and stores them persistently in ChromaDB.
    \item \textbf{Query Scope Detection:} Parses user question syntax to identify target quarters (Q1--Q4) and target metric types (Revenue, EBIT, Net Income).
    \item \textbf{Hybrid Candidate Retrieval:} Queries 1024-dim question embeddings (\texttt{input\_type="query"}), scores top candidates, and extracts top 5 passage chunks.
    \item \textbf{Grounded LLM Synthesis:} Synthesizes executive financial answers using NVIDIA NIM LLM with zero-temperature strict prompt rules.
\end{enumerate}
